PRG4206 outputs
================
PRG4206_Project_Outputs_Summary.pdf in the initial submission ZIP is a summary of the saved benchmark artefacts. It clearly notes that it is not evidence of a Google Colab execution.

Run notebooks/00_PRG4206_Colab_Run_and_Outputs.ipynb in Google Colab to run the tests, statistical verification, model inference, and document parsing checks. The notebook writes outputs/colab_runtime.json and regenerates the PDF with the actual runtime record.
